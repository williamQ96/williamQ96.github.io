Selected systems & research

Work you can inspect.

01 Accountability

Patra ModelCards

Lifecycle model cards that capture structured metadata, fairness, explainability, version relationships, and deployment history as machine-actionable records.

Model documentation stays connected to how a model is trained, revised, and used.

Documentation Toolkit Knowledge base
02 Infrastructure

Cyberinfrastructure Knowledge Network

A distributed framework connecting edge devices and cloud services through event streams, historical performance data, and adaptive AI-model deployment.

Runtime observations connect edge decisions back to model provenance.

Documentation GitHub Paper
03 Metadata

Auditable Metadata Augmentation

A multi-pass approach for augmenting model cards and datasheets while preserving the prompts, methods, corpus manifests, and aggregate evaluation behind each result.

The artifact package exposes the full path from method to evaluation.

Artifacts Results
04 Evidence

NexusLLM / Patra-RGCN

Knowledge-graph research that studies missing relationships in model-card graphs and uses structured node properties to improve link prediction.

Code and a DOI-referenced dataset make the evaluation path inspectable.

GitHub Dataset
05 Infrastructure

NSF ICICLE AI Institute

The Plale Lab has been a leader in the NSF ICICLE AI Institute since its inception in 2021, helping advance accessible and trustworthy AI cyberinfrastructure.

The institute's unified services and training resources make shared cyberinfrastructure easier to discover and use.

Institute Services board Training catalog
06 Community

We're active!

The Plale Lab participates in the CENTRA Consortium, endorses the FAIR Digital Objects approach, and contributes to international data governance through Beth Plale's service on the DONA Foundation Board of Directors.

Research infrastructure connects technical systems with international standards, partnerships, and governance.
